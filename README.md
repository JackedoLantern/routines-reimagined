# Routines Reimagined: public website

This folder is the whole website. Upload it to any free static host and you get a public link
that anyone can open, with no Claude account needed. On a phone, people can add it to their
home screen and it opens full screen like an app, even offline.

## Fastest way: Netlify Drop (about 1 minute, free)
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. You get a public link right away. Make a free account to keep it and pick a nicer name.

## Other free options
- GitHub Pages: make a repository, upload these files, then Settings > Pages > deploy from the main branch.
- Cloudflare Pages: upload the folder as a direct upload project.

## Install it like an app
- iPhone: open the link in Safari > Share > Add to Home Screen.
- Android: open the link in Chrome > menu > Install app (or Add to Home screen).

## What works in this version
Workouts with how-to guides, My day, Diet and meal plans, your own tabs, offline Skeefo,
XP, levels, streaks, badges, sounds and animations. Progress is saved on each person's own device.

The leaderboard, family groups, parent reports and Skeefo's Claude brain need Claude
accounts, so they're only in the Claude version of the app.
